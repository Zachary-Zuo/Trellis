# Backend Development Guidelines

> 本项目 backend 开发的约定。

---

## Overview

本目录存放 backend 开发约定。

index 是地图，不是清单：每行指向一个文件，并说明什么时候该读它。

写文件时只写代码库能证明的约定；某个文件对本项目不适用时直接删除，不要留着占位。

---

## Guidelines Index

| 文件 | 内容 | 何时读 |
|------|------|--------|
| [directory-structure.md](./directory-structure.md) | 模块划分与文件摆放 | 新增模块、或不确定代码该放哪时 |
| [database-guidelines.md](./database-guidelines.md) | ORM 用法、查询、migration | 改表结构、写查询或 migration 时 |

| [quality-guidelines.md](./quality-guidelines.md) | 代码标准、禁止的写法 | 写代码与 review 时 |
| [logging-guidelines.md](./logging-guidelines.md) | 结构化日志与日志级别 | 加日志、或排查线上问题时 |
